# V16 Flyover UI refinement

V15 improved 3D camera only. V16 is a UI-focused revision: merge camera modes, stats toggle and free exploration into an accessible camera options menu; replace the four-button speed strip with a compact single-tap cycle 0.5x -> 1x -> 2x -> 4x -> 0.5x; retain direct cinema-mode toggle and one-handed Play/Pause and seek; reduce HUD material opacity and radius and animate mode changes.

No change to GPS samples, HealthKit permissions, routes, saved workouts, or accepted plans. Source-focused UI tests and iPhone compilation pass; real tap usability and perceived readability still need physical QA.
